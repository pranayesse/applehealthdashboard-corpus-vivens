The service is running on this Mac. Three things left, all on your phone. This page goes green the moment the first sync arrives.

  1. Open Health Auto Export on your iPhone

    Go to the Automations tab and add a new automation. Set its type to REST API, the method to POST and the format to JSON.

  2. Paste in these two values

    The URL goes in the address field. The header is added under the automation's headers section — name on the left, value on the right.

  3. Choose what to send, then turn it on

    Select the metrics you want — all of them is fine, anything unrecognised is stored rather than dropped. Set the interval to every 5 minutes.

    For a heart that genuinely tracks you rather than showing one number all day, set the aggregation granularity finer than daily. Hourly or better.

Waiting for the first sync…

Leave this page open. It checks every few seconds.

If nothing arrives. Almost always one of three things: you missed the macOS prompt asking whether node may accept incoming connections, the phone is on a different Wi-Fi network, or the header value is missing the word Bearer before the token.

Once data is flowing, the plate is at http://localhost:8080.
